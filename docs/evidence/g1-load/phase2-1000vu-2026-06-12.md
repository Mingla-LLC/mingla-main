## Findings

1. **Discover is the bottleneck** — avg latency ~6.4 s at 1k VU; 2 requests hit 30 s k6 timeout. Likely DB/query or edge-fn CPU on merged-events path. Checkout edge fns stay sub-200 ms p95 at same concurrency.
2. **First attempt (Docker k6, instant 1k VU)** — connection refused / EOF at ~18 s; wedged Docker daemon. Switched to native k6 + ramping VUs.
3. **Harness updates (local):** `lib/scenario.js` ramp for `LOAD_VUS >= 100`; checkout scripts use `checks` thresholds; `run-staging.sh` passes `LOAD_RAMP_DURATION`, Docker `ulimit`.
