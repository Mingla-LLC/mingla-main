# Positioning Framework

## Inputs

- Target customer
- Customer pain
- Current alternative
- Category
- Main benefit
- Differentiator
- Proof
- Reason to believe

## Positioning Statement

For [target customer],
who [pain/job],
[product] is a [category]
that [benefit].
Unlike [alternative],
[product] [differentiator].

## Messaging Tests

Good positioning should be:

- Specific
- Differentiated
- Valuable
- Believable
- Repeatable by sales
- Obvious to the target customer

## Website And Landing Page Copy

Provide:

- Hero headline
- Subheadline
- CTA
- Problem section
- Value props
- How it works
- Proof points
- Use cases
- Objection handling
- FAQ
- Final CTA

Copy should be specific, direct, and benefit-led.
