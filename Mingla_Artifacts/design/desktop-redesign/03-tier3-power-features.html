Feature 1
⌘K command palette

Type to jump to any event, order, guest, page, or run a verb (refund, refund-selected, compose blast, open scanner). Replaces tabs as the primary nav for power users.

Feature 2
Multi-select + bulk

Refund 12 orders at once. Comp 30 guests. Cancel 5 pending. Each is a 4-tap mobile flow today; collapses to one click on desktop.

Feature 3
Keyboard navigation

J/K for list traversal, X to select, ⏎ to open, Esc to close sheets, ⌘S to save, G+letter for direct page jumps. Desktop muscle memory.

Feature 4
Right rail context

Today's pulse, refund SLA breach alerts, offline-scanner warnings, live Ari recommendations — visible while you work, not buried in tabs.
