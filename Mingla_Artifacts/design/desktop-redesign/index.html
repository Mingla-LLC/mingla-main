Stop looking like a phone trapped on a desktop.

Mingla Business runs on iOS, Android, and the web via React Native. On a 27" monitor, the mobile layout gets stretched and floats inside a sea of empty canvas. These mockups walk through three tiers of fixes — from a 1-day visual lift to a full desktop-native interaction model — all while keeping the mobile app pixel-identical.

Out of scope for this brainstorm
  • · Buyer-anonymous web routes (/checkout/{eventId}, /e/{brandSlug}/{eventSlug}, /b/{brandSlug}) — these are conversion-focused single-purpose pages, more like Stripe Checkout than a tool. They want their own narrow-column treatment, not a sidebar shell. Separate workstream.
  • · Tablet / landscape phone breakpoint (641–1023px) — Tier 1's isWideDesktop guard fires at ≥1024px. Below that we keep the current mobile shell. A 3rd middle breakpoint is worth doing but is a separate spec.
  • · Mingla Admin (mingla-admin/) — already a true desktop React+Vite app. Not in scope; only mingla-business needs desktop adaptation.
  • · Light mode — these mockups are dark-only to match Mingla's current brand canvas. Light mode for desktop is a separate decision.
