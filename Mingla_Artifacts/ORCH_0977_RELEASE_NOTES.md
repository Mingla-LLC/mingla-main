## Notes for the operator

- **Positioning:** copy follows the house rule — Mingla is an experience / plan-making app, NOT a dating app. No "dating," "matches," or "singles" language.
- **No prohibited terms:** avoids "Best," "#1," "New," "Top," price/promo language (both stores' content guidelines forbid these in promotional fields).
- **Contact Support callout:** both versions point users to the new in-app Contact Support link (added 2026-05-28 in Settings → App Information), which doubles as the Apple Guideline 1.2 published-contact path.
- **Future releases:** for subsequent updates, replace with specific changelog bullets ("Fixed…", "Added…", "Improved…"). This launch copy is intentionally introductory since it's the first public version.
- **Character counts:** Play version ≈430/500; App Store version ≈700/4000. Both have headroom.
