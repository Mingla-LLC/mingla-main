# Spec: Rich Social Link Preview + SEO Snippet (ORCH-0763E)

> Date: 2026-05-09  
> Investigation: `Mingla_Artifacts/reports/INVESTIGATION_ORCH-0763E_RICH_SOCIAL_LINK_PREVIEWS.md`  
> Root cause: RC-0763E-1 and RC-0763E-2  
> Status: ready for orchestrator review, then implementor dispatch

## 1. Layman Summary

Mingla public event links should look trustworthy before someone taps them.

This spec adds a real server-side preview layer for public event and brand URLs. Messaging apps and social crawlers will receive event-specific title, description, canonical URL, and a valid branded image. Browser users still land on the normal Expo public page.

## 2. User Story

As an organiser, I want my shared event link to show the event name, Mingla branding, and event cover image, so guests trust the link and are more likely to open it.

As a guest, I want the shared link preview to tell me what event I am opening before I tap.

## 3. Scope

- **In scope:**
  - Crawler-visible metadata for `/e/{brandSlug}/{eventSlug}`.
  - Crawler-visible metadata for `/b/{brandSlug}`.
  - Real OG image endpoints for `/og/event/{eventId}.png` and `/og/brand/{brandSlug}.png`.
  - Shared pure metadata builders for event/brand titles, descriptions, canonical URLs, image URLs, and privacy-safe text.
  - Tests and deployed smoke gates.
- **Non-goals:**
  - Redesigning public event or brand page UI.
  - Changing canonical domain away from `https://business.usemingla.com`.
  - Fixing native share-sheet internal Copy.
  - Changing checkout/payment behavior.
  - Adding paid SEO tooling.
- **Assumptions:**
  - `business_public_events_view` remains the public read model.
  - Uploaded event cover images in `event_covers` are public-readable.
  - Vercel remains the host for `business.usemingla.com`.
- **Dependencies:**
  - Vercel production deploy after implementation.
  - Social preview manual retest because iMessage/WhatsApp/Facebook/X cache previews.

## 5. Success Criteria

1. `curl -A 'facebookexternalhit/1.1' https://business.usemingla.com/e/{brandSlug}/{eventSlug}` returns HTML containing event-specific `title`, `description`, `og:title`, `og:description`, `og:url`, `og:image`, `og:image:width`, `og:image:height`, `twitter:card`, `twitter:title`, `twitter:description`, `twitter:image`, and canonical tags before JavaScript runs.
2. `curl -A 'WhatsApp/2.24.0 i'` against the same URL returns the same event-specific metadata.
3. `curl -I https://business.usemingla.com/og/event/{eventId}.png` returns `200`, `content-type: image/png`, and cache headers.
4. Event preview image is 1200x630 and includes:
   - Mingla logo,
   - event name,
   - event cover image as the dominant visual when an image cover exists,
   - branded fallback when no usable cover image exists.
5. Brand preview URLs follow the same metadata/image contract for `/b/{brandSlug}` and `/og/brand/{brandSlug}.png`.
6. Private/draft/hidden/deleted events do not expose metadata; not-found previews return a noindex/not-found response.
7. Event previews never expose hidden/private address details when `hideAddressUntilTicket` is true.
8. Existing browser public event and brand pages still hydrate and render normally.

## 8. Edge Functions / RPCs / Webhooks

Preferred implementation uses Vercel serverless/edge functions inside `mingla-business`, not Supabase edge functions.

### Public metadata shell functions

- **Path:** new Vercel functions under `mingla-business/api/public-event-shell.ts` and `mingla-business/api/public-brand-shell.ts`, or equivalent route-specific files supported by Vercel.
- **Auth:** public; use Supabase anon access only.
- **Request schema:**
  - event shell: `brandSlug`, `eventSlug`
  - brand shell: `brandSlug`
- **Success response:** `text/html; charset=utf-8` containing the normal Expo app shell plus injected metadata tags in `<head>`.
- **Not found:** return `404` or `200` with noindex only if Vercel/Expo routing requires app shell fallback; must not emit fake event metadata.
- **External calls/timeouts/retries:** one Supabase public view fetch; set an explicit timeout. If metadata fetch fails, return safe Mingla fallback metadata and log the failure.
- **Deploy notes:** Vercel config must route canonical public URLs through these functions while preserving app hydration.

### OG image functions

- **Path:** new Vercel functions for:
  - `/og/event/{eventId}.png`
  - `/og/brand/{brandSlug}.png`
- **Auth:** public; fetch only public rows.
- **Success response:** `image/png`, 1200x630, with cache headers.
- **Error response:** stable Mingla fallback PNG, not text, unless event/brand is private/not found and the safer behavior is `404`.
- **External calls:** fetch public cover/profile image only if it is HTTP(S), public, and image-like. Do not use video as `og:image`.
- **Implementation library:** use a proven Vercel-compatible image rendering library such as `@vercel/og` or an equivalent. Add the dependency explicitly and document why.

If Vercel function support cannot be made to work with the existing Expo static deployment, stop and return to orchestrator with the failed proof. Do not degrade to client-only metadata.

## 9. Service Layer

### Public preview data fetchers

- **Path:** new `mingla-business/src/services/publicPreviewService.ts` or server-only equivalent.
- **Signatures:**
  - `getPublicEventPreviewBySlug(brandSlug: string, eventSlug: string): Promise<PublicEventPreview | null>`
  - `getPublicEventPreviewById(eventId: string): Promise<PublicEventPreview | null>`
  - `getPublicBrandPreviewBySlug(brandSlug: string): Promise<PublicBrandPreview | null>`
- **Query behavior:** read `business_public_events_view`; never read drafts/private rows directly.
- **Error contract:** throw/log infrastructure errors; return null for not found/private.
- **Return type:** minimal preview-safe object, not full `LiveEvent`.

### Pure metadata builders

- **Path:** new `mingla-business/src/utils/publicPreviewMetadata.ts`.
- **Functions:**
  - `buildEventPreviewMetadata(input): PublicPreviewMetadata`
  - `buildBrandPreviewMetadata(input): PublicPreviewMetadata`
  - `buildEventOgImageUrl(input): string`
  - `buildBrandOgImageUrl(input): string`
- **Contract:** pure, deterministic, unit-tested, no network calls.
- **Required output fields:**
  - `title`
  - `description`
  - `canonicalUrl`
  - `ogTitle`
  - `ogDescription`
  - `ogUrl`
  - `ogImage`
  - `ogImageWidth: 1200`
  - `ogImageHeight: 630`
  - `ogType`
  - `twitterCard: "summary_large_image"`
  - `twitterTitle`
  - `twitterDescription`
  - `twitterImage`
  - `robots` when needed

Existing `eventOgImageUrl(...)` and `brandOgImageUrl(...)` in `src/constants/publicUrls.ts` must either delegate to the new builders or be narrowed so they no longer bless nonexistent paths without endpoints.

## 16. Regression Prevention

- **Structural safeguard:** crawler metadata must be generated server-side, not only through React `<Head>`.
- **Test:** add a test that fails if generated public event HTML lacks `og:title`, `og:image`, `twitter:image`, or canonical.
- **Test:** add an endpoint/header test for `/og/event/{id}.png` and `/og/brand/{slug}.png`.
- **Protective comment:** document in `PublicEventPage` and `PublicBrandPage` that React `<Head>` is parity only; crawler authority lives in the server metadata shell.
- **Artifact update:** implementation report must mention ORCH-0763E and link this spec.

## 17. Rollback And Deploy Safety

- **Migration order:** no migration expected.
- **Edge function deploy:** no Supabase edge deploy expected if Vercel implementation is used.
- **Mobile OTA vs native build:** no native rebuild required for preview metadata; this is web/public infrastructure.
- **Business/admin web deploy:** Vercel production deploy required.
- **Env vars/secrets:** Vercel functions need `EXPO_PUBLIC_SUPABASE_URL`, `EXPO_PUBLIC_SUPABASE_ANON_KEY`, and `EXPO_PUBLIC_MINGLA_BUSINESS_WEB_URL`. Do not introduce service-role keys for public preview functions.
- **Partial rollback risk:** if Vercel rewrites are wrong, public event pages can become unavailable. Keep a rollback path to previous static rewrites.
- **Cache risk:** platform previews may cache old metadata. Tester must use a freshly created event or a changed slug/image for final proof.

## 18. Common Mistakes

1. Editing only `PublicEventPage` `<Head>` and expecting crawlers to see it.
2. Leaving `/og/event/*.png` as a string-only helper without a deployed image endpoint.
3. Using raw video/GIF cover URLs as `og:image`.
4. Exposing hidden address or ticket-gated details in metadata.
5. Hardcoding `mingla.com` or `business.mingla.com`.
6. Trusting local source while Vercel production is still stale.
7. Testing only in a browser tab instead of with crawler user agents.
