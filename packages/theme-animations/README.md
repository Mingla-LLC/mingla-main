# @mingla/theme-animations

ORCH-0964 entrance-animation assets for public brand and event theming.

All nine Lottie JSON files in `lottie/` are generated in-house for Mingla from simple tintable vector shapes. They do not include third-party images, fonts, or externally sourced artwork. Each animation is intentionally small and uses a `theme fill` layer so `lottie-react-native` `colorFilters` can tint the animation to the selected theme color.

Animation slugs:

- `confetti`
- `fireworks`
- `balloons`
- `sparkles`
- `glitter_shower`
- `snowfall`
- `falling_petals`
- `hearts`
- `shimmer_reveal`
