  1. Click Copy signature above.
  2. In Gmail, open Settings (gear icon) → See all settings.
  3. Scroll to Signature → Create new (name it “Mingla”), click into the box and paste (Cmd/Ctrl + V).
  4. Under Signature defaults, set it for new emails and replies. Scroll down and Save Changes.

Tip: if you paste into the box and the logo looks broken on first try, give it a second — Gmail fetches the images from usemingla.com the first time. On mobile Gmail, edit your signature from the desktop site once and it syncs everywhere.
